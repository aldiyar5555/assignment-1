## Project Overview

This assignment contains five HTML pages that demonstrate modern front-end development using semantic HTML and advanced CSS styling. Each page includes a shared navigation bar and follows a consistent visual theme with modern colors, shadows, and polished typography.

## Pages Included

- `index.html` — Task 1: Personal profile page for Aldiyar Aimbetov with a student card, skill list, interests, and profile links.
- `task2.html` — Task 2: Float-based layout with sidebar, content panel, and structured section navigation.
- `task3.html` — Task 3: Tribute page for Alan Turing featuring timeline, achievements, quote block, and external link.
- `task4.html` — Task 4: Academic table with row/column spans and a complete feedback form.
- `task5.html` — Task 5: Midterm project proposal with sitemap and visual wireframe layout simulation.

## Styling Structure

- `styles/global.css` — Shared navigation, layout reset, typography, and global design system.
- `styles/task1.css` — Profile card styling and responsive layout.
- `styles/task2.css` — Float-only layout implementation without Flexbox or Grid.
- `styles/task3.css` — Tribute page visual design and polished typography.
- `styles/task4.css` — Table zebra striping, form styling, and responsive panel layout.
- `styles/task5.css` — Sitemap cards and wireframe presentation for the midterm proposal.
